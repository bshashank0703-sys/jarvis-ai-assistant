
# JARVIS AI Assistant

A personal AI voice assistant for Android.

## Project Goals
- Futuristic blue assistant interface
- Voice input and spoken responses
- Online AI integration
- Phone utility commands
- Reminders and device settings
- Lightweight design for Android phones with 4 GB RAM

## Technology
- Kotlin
- Android
- GitHub Actions
- Supabase (optional)
- Vercel (optional web dashboard)

## Status
Project setup in progress.
